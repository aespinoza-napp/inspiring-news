### Fixes

- **`scripts/e2e.py` on Windows.** It died with `FileNotFoundError` on
  `npm` (Windows has `npm.cmd`, which `subprocess` without a shell does not
  find). Behind that, it hands Chrome its DevTools pipe as file
  descriptors 3 and 4 (`preexec_fn`, `dup2`) and stops the server by
  process group, neither of which exists on Windows: `trends.md` already
  said it "needs a POSIX machine". It now exits 2 with that sentence. No
  CI job runs it, so on this machine the polling and TikTok guards are
  held only by checks run by hand.
- **CLAUDE.md**: "the LLM's accuracy has never been measured" was false
  since 13 Oct; it now says it is measured only on unreviewed labels.
  "~22 topics" is 23.
- **`data/evaluation/README.md`, roadmap**: the joined file exists and is
  derived; nothing checks that it is current, so `join` must be re-run
  after the review. The roadmap records the join and that the re-label
  has not started.

### Join

`backend/data/evaluation/custom_en_es.jsonl`: the 139 facts, x-fact's
keys first, every row with its `split`. Joined *before* the review of the
AI labels, so it will be stale as soon as one label changes. The harness
reads `manual/` directly as well, and a run's key includes the dataset's
hash, so a stale join cannot mix two gold sets in one run.
