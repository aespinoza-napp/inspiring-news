\subsection{Tools}
\label{subsec:tools}

Git, with a development branch merged into the main one; GitHub
Actions running the same \texttt{check.sh} targets on every push;
Docker Compose for the services; \texttt{uv} and \texttt{npm} for
dependencies.
Two further tools keep the plan honest. The roadmap
(\path{docs/roadmap.md}) is checked against the code rather than the
plan: an item is ticked only when it is done and verified, and its note
says how. Decision records (\path{docs/decisions/}) keep the reason
behind each design choice and each incident.
