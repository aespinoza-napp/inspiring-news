\section{Pilot on X-Fact}
\label{sec:results-pilot}

The first run of the full pipeline against labelled data: X-Fact
\cite{gupta2021xfact}, the open-retrieval benchmark chosen in
Section~\ref{subsec:xfact}. It served two purposes. It shook out the
evaluation harness against live services before the custom set is
settled, and it places the system beside the numbers Gupta and
Srikumar publish for their benchmark. The second purpose turned out to
be the harder one: thirteen years separate some of the claims from the
web the system searched, and that distance changes what an X-Fact
score means.
