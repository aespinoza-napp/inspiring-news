## 3. Findings

### High

**H1 — The search answered about the wrong thing, and nothing noticed.**
Through SearXNG, from this machine, Bing returned ten results for every
query about its first word only ("cervical cancer vaccination Africa" →
neck pain), while Google, Brave and Yep were suspended. Every claim's
evidence was off-subject and its verdict an honest-looking UNVERIFIED;
the source probe and `/metrics` counted results, so both looked healthy.
Fixed in configuration today (`docker/searxng/settings.yml`; on-topic
results: DuckDuckGo 25/29, Startpage 25/30, Bing 1/30). The re-run found
the claims' real sources (the South African health department, Statistics
South Africa). When it started is unknown: the 16 harness runs here, up to
30 Oct, look healthy (63-89% of web titles share a claim word, 65-70% on
the 7 full runs; 0-11% off-subject domains;
`scripts/evidence_on_subject.py`, a rough screen); the 22 Oct runs are on the other
machine. *Still missing: any check of relevance.*

**H2 — The ground truth has not moved since 20 October.** 108 of 139
labels are the AI pass's, unreviewed; the review (U1) was due 30 Oct; the
blind re-label of 14 has not started; 0 of 139 facts are timed; 28 thesis
placeholders. Every custom-set figure in chapters 7 and 9 rests on it.

**H3 — The contrast edition is published to the public reader.** The
Devastating edition (unverified by design, ironic, on terrorism, suicide
and racism) is meant as a contrast and not for production (author, 3 Nov),
but nothing enforces that. `GET /reader/articles` and `/reader/stories`
are open, return both editions unless asked for one, and feed the public
RSS and sitemap; neither the production compose file nor Terraform turns
the edition off. One Devastating analysis on a deployed server would be
readable without the password.

### Medium

**M1 — Secrets one command from the remote.** `backend/.env.bak-2026-11-02`
(untracked) carries `LLM_API_KEY`, `NEO4J_PASSWORD` and `SEARXNG_SECRET`.
`.gitignore` lists `.env` exactly, so this name is not ignored. No `.env`
file is anywhere in git history, and the one API-key pattern match at `HEAD`
is an ID in a Reddit fixture (`HEAD` and known key formats only).

**M2 — One misread source withholds an article.** After the search fix the
HPV article's evidence was right and two claims came back TRUE at 97%,
but the 3B marked two sources as contradicting a claim while quoting that
same sentence from each; worst-claim-wins made the article FALSE and
withheld it. The model is the limit, as RQ2 says; a guard (a source whose
quote contains the claim cannot contradict it) is a decision for the
evaluation, not taken.

**M3 — Work and records not where they can be reproduced.** A day of
changes uncommitted (45 files, 18 new), `feature/news-map` unmerged, run
records split between two machines (28 Oct N2), the engine list changed.

**M4 — The overview documents still describe September.** Unchanged from
16 Oct: architecture v1.1 (28 Sep, 36 sources), the executive summary (no
ingestion, no measured accuracy; promises a recommender and a mobile app).
