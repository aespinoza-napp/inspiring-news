## 2. Fixed in this session

### The thesis build

1. **Every `tabularx` failed** with `Undefined control sequence
   \insert@pcolumn`. `xcolor` was loaded with `table`, which pulls in
   `colortbl`; MiKTeX fetched its 2026 release, which needs the 2024
   `array.sty`, while MiKTeX 24.1 ships the 2023 one. Nothing in the
   document colours a table cell, so the option was dropped
   (`main.tex`, with the reason in a comment).
2. **The MiKTeX install lacked ten packages** the preamble needs
   (`setspace`, `parskip`, `caption`, `pgfgantt`, `enumitem`...). They
   were installed with `mpm`. MiKTeX's auto-install is set to *ask*,
   which opens a dialog and hangs any headless build; run `pdflatex
   --enable-installer` or install packages explicitly.

long articles, and with them the claim selector's inputs; made before
any custom-set run, so no reported number moves.
