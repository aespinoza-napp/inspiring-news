## Proposed change

**What:** `checkable_figures: with_units`, a new threshold (default `bare`, as every earlier run). A figure with a currency sign (£ $ € ¥), a short unit or scale suffix (1-3 letters), or both written onto it is kept as written and becomes a checkable figure. Examples: "£5.9bn", "189p", "$40m", "3,5kg", "50GW". Excluded:
- ordinals in either language ("21st", "2nd", "3er", "2do", "4to");
- one digit with a letter and no sign ("5G", "3D").

A sign or a unit counts as distinctive, like a decimal, so such a figure sorts first and makes the point `specific`. This is a class of token, not these claims' words: UK, US and Spanish news write money and quantities this way.

**Where:**
- `backend/src/services/fact_checker/retrieval/checkable.py`: `UNIT_FIGURE`, `unit_figures`, `figures_of(text, units=)`, `checkable_point(..., figures_style)`, `point_for_thresholds`.
- The planning plumbing: `query_builder.plan_checkable`, `plan_queries`, `plan_arguments`, `SearchProvider.plan`. `search` now uses `plan_arguments` too, so the two cannot drift.
- The threshold: `config/thresholds.py` (both classes) and `settings.CHECKABLE_FIGURES`.
- The run key: `runner._SPEED_BEFORE`, and `iterate.SEARCH_SIDE` / `_BEFORE_IT_EXISTED`, so a run with `bare` keeps its key.
- The fakes' `plan` signatures.

**Tests:** in `tests/services/fact_checker/retrieval/test_checkable.py`, on fact099's and fact101's sentences:
- the default is unchanged;
- each figure is kept;
- what counts as a unit figure;
- "£40" does not cut into "£400m";
- the anchor query quotes "£5.9bn";
- the run key is kept;
- the `searching_web` event shows the figure.

`./scripts/check.sh fast`: "All checks passed." `uv run pytest tests/services/fact_checker tests/evaluation`: "706 passed, 3 xfailed".

**Lever:** `{"checkable_figures": "with_units"}` on the base. **Mode:** offline here. Downstream it changes what is searched, so the verdict-level test is a searched try (`proposal.json`'s `iterate`).

**Prediction:**
- fact099 gains £5.9bn (share 0.6 → 0.8; "gas imports" stays missing).
- fact101 gains 189p (0.833 → 1.0), so `checkablePointAllCarried` goes from 6 to 7.
- The other 18 claims are unchanged. Going through their sentences by hand, none has a sign or unit on a figure. fact122's "3I" is one digit with no sign. fact088's "15‑PGDH" uses a non-breaking hyphen and reads as before.
- `checkablePointCoverage` rises a little from 0.813; the script computes the figure. `sentencePlanCoverage` stays 0.523.

This is predicted from the code and the tests. The hook does not allow a throwaway script, so it was not run on the batch.

**What could get worse:**
- Only three figures are kept, and a unit figure now sorts first. In a sentence with more than three figures it can push out a bare number that mattered. That is the one way the held-out batch can fall.
- Glued tokens that are not quantities ("10am", "1990s") become figures. They are not distinctive, so they only take a figure slot.
- On the search side, a quoted "£5.9bn" may not match a page that writes "£5.9 billion". That is stage 02/03's to measure.
