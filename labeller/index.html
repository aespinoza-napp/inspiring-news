Tie-break rules
  1. The organisation's own source. If only the NGO's or company's own release, report or post backs the claim → UNVERIFIED. Tick the box and name the source in the note.
  2. Numeric tolerance. Within ±10% relative of the source (30% against 28%), or a reasonable rounding, is supported. Beyond that: PARTIALLY_TRUE if the figure is a detail, FALSE if the figure is the claim.
  3. Date of the evidence. Only evidence available on the article's publication date. Something confirmed later does not change the verdict.
  4. Source hierarchy. Primary (report, official statistic, study) > reference media > press release > social media. The higher tier wins a conflict; a conflict within one tier is MISLEADING. Record the strongest source used.
